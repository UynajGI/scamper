# 重命名：`spin_boson` → `impurity`

## 范围

这次重命名是**纯机械的**——不改变任何逻辑、不新增/删除任何功能。改完后 `cargo fmt --check`、`clippy -D warnings`、全 workspace 测试 全部照旧通过。

### 1. 模块路径重命名

| 旧 | 新 |
|---|---|
| `QMC.rs/src/spin_boson/` | `QMC.rs/src/impurity/` |
| `pub mod spin_boson` | `pub mod impurity` |
| 所有 `use crate::spin_boson::` | `use crate::impurity::` |
| 所有 `use super::spin_boson::` | 已在同目录的 `use super::`（不需要 `::spin_boson`）|

### 2. 5 个类型名：`SpinBoson` → `Impurity`

| 旧 | 新 |
|---|---|
| `SpinBosonError` | `ImpurityError` |
| `SpinBosonModel` | `ImpurityModel` |
| `SpinBosonModelKind` | `ImpurityModelKind` |
| `SpinBosonQmc` | `ImpurityQmc` |
| `SpinBosonObservables` | `ImpurityObservables` |

### 3. 变体名

`SpinBosonModelKind::RotatedSpinBoson` → `ImpurityModelKind::RotatedImpurity`

### 4. 文件名重命名（`git mv`）

| 旧 | 新 |
|---|---|
| `tests/spin_boson_physics_test.rs` | `tests/impurity_physics_test.rs` |
| `tests/spin_boson_wormhole_test.rs` | `tests/impurity_wormhole_test.rs` |
| `examples/spin_boson_wormhole.rs` | `examples/impurity_wormhole.rs` |

### 5. 字符串字面量（按出现位置）

**模型元数据名：**
- `"RwCrwSpinBoson"` → `"RwCrwImpurity"`
- `"XxzSpinBoson"` → `"XxzImpurity"`
- `"XyzSpinBoson"` → `"XyzImpurity"`
- `"RotatedSpinBoson"` → `"RotatedImpurity"`

**交互通道名 & 模型选择参数别名：**
- `"rotated_spin_boson"` → `"rotated_impurity"`（交互通道名+参数别名）
- `"spin_boson"` / `"spin-boson"` → `"impurity"`（模型选择参数+`to_carlo_error` 字段名）

**错误信息：**
- `"spin-boson wormhole sweep failed"` → `"impurity wormhole sweep failed"`
- `"spin-boson measurement failed"` → `"impurity measurement failed"`

**`name()` 返回值：**
- `"SpinBosonQmc"` → `"ImpurityQmc"`

### 6. 文档注释（doc comments）

所有源码内 `//!` / `///` 中的 "spin-boson" 统一改为 "retarded impurity" 或 "impurity"（视上下文不改变物理含义）。

### 7. 仓库文档

- `CLAUDE.md` line 94：`spin_boson` → `impurity`
- `docs/metaphysics/2026-04-09-qmc-rs-philosophy.md` line 52：`SpinBosonMonteCarlo` → `ImpurityMonteCarlo`
- `docs/ref/md/Weber - 2022 - ...md`：**不动**（引用的学术论文，不是我们的代码）
- `target/`：不手动改，`cargo build` 会自动重新生成

### 8. 不改的东西

- 测量键（如 `"MagnetizationSigmaZ"`）：这些描述的是物理量，与模块名无关
- 顶点名 / 通道内部名（`"jc"`, `"xxz"`, `"xyz"`）：已经是通用的模型标识符
- `Bath`、`SingleModeBath`、`PowerLawBath`、`TabulatedBath`：这写是 bath 类型的名字，不需要修改（虽然它们在 impurity 模块下）
- `WormholeConfiguration`、`WormholeEngine`：算法名，不涉模型名

### 9. 对 crate 外部用户的影响（qmc_rs 的公共 API）

所有 `pub use` 和 re-export 已同步更新。外部代码原先写：

```rust
use qmc_rs::spin_boson::SpinBosonQmc;
```

现在写成：

```rust
use qmc_rs::impurity::ImpurityQmc;
// 或者直接用 crate root re-export
use qmc_rs::ImpurityQmc;
```

### 10. 执行步骤

1. `git checkout -b rename-spin-boson-to-impurity`
2. `git mv` 目录和文件
3. 用 `sed` 全局替换所有类型名、模块路径、字符串字面量
4. 手动修正 `CLAUDE.md` 和 `docs/metaphysics/`
5. `cargo fmt --all`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`
6. 如果全绿则 commit
